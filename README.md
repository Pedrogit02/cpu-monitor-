# CPU Monitor 

# Sobre o projeto

CPU Monitor é um projeto desenvolvido em Python para consultar e analisar
processos em execução no Linux, permitindo identificar processos com maior
consumo de CPU.
O projeto utiliza comandos do sistema operacional por meio do módulo
"subprocess" do Python

# Funcionalidades

-Consulta de processos em execução no Linux.
-Organização dos processos por consumo de CPU.
-Identificação de processos acima de um limite de utilização definido pelo
usuário.
-Investigação de processos específicos por meio do PID.
-Exibição de informações como usuário, PID, nome do processo e 
percentual de CPU.

# Tecnologias utilizadas

-Python 3
-Linux 
-Módulo subprocess 
-Comandos de gerenciamento de processos 

# Execução

python3 CPU_monitor.py

# Objetivo 

Praticar Python aplicado à administração de sistemas Linux, automação de tarefas
e monitoramento de processos.
